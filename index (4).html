Storage & Privacy

This standalone file uses browser localStorage, not a central server or MySQL database. Records stay in this browser profile and may be lost if browser data is cleared.

Do not use this demo for real sensitive student records, Aadhaar details or confidential certificate files. A secure multi-user deployment requires a backend and access controls.
